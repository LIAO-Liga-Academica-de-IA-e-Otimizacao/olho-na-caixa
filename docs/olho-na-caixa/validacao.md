# Validação

O número que entra no relatório vem de um segundo grupo de caixas. Esse grupo é fotografado depois que os coeficientes já foram travados. O primeiro grupo só serve para ajustar esses coeficientes. São, portanto, dois grupos, com papéis diferentes.

## Calibração

A calibração usa cerca de 30 caixas por item, para tangerina e para tomate. Nesse grupo se ajustam o passo entre camadas e os quilos por litro. Cada caixa guarda:

- o modelo da caixa e as medidas internas;
- a variedade;
- a altura do monte medida com régua;
- o vídeo do arco;
- a verdade de referência: contagem dupla, no caso da tangerina, e peso de balança, no caso do tomate.

A contagem dupla vale quando os dois contadores diferem em menos de 2%. Se diferirem mais do que isso, um terceiro conta. A balança dessa etapa pode ser lenta. O limite de um minuto vale para o operador na demonstração. Quem está etiquetando as caixas de calibração não está sujeito a esse limite.

O ajuste usa validação deixando uma caixa de fora de cada vez, para escolher o coeficiente. Em cada rodada, uma caixa fica fora do ajuste e serve só para ver se o coeficiente escolhido com as outras ainda funciona nela. Esse procedimento escolhe o coeficiente. O erro medido nele ainda não é o número publicado.

## Conjunto congelado

O conjunto congelado tem pelo menos 20 caixas por item. Essas caixas são fotografadas em outro dia, por outra pessoa, depois que os coeficientes já foram travados. Ninguém mexe no passo nem nos quilos por litro depois de olhar esse conjunto.

Em cada caixa i, o erro relativo é:

> **eᵢ = (estimativa − verdade) / verdade**

O relatório mostra, por item:

- o viés, que é a média de eᵢ, e fica positivo quando o aplicativo estima para mais;
- a margem de erro média, que é a média de |eᵢ|;
- o desvio padrão amostral de eᵢ, que divide a soma dos quadrados dos desvios por n − 1;
- a fração de caixas em que |eᵢ| ficou dentro de 10%;
- o percentil 90 de |eᵢ|, isto é, o valor abaixo do qual caíram 90% dos erros absolutos.

A meta do edital, do jeito que está escrita hoje, compara o resultado com a margem de erro média. A fração de caixas dentro de 10% e o percentil 90 acompanham o relatório para a leitura caixa a caixa.

## Para que servem fotos públicas de fruta

Fotos públicas de fruta servem, no máximo, para o detector começar menos cego. Nenhuma delas traz o quilo por litro da caixa desta cozinha. Esse número só existe nas caixas pesadas pelo time.
